# La Usina del PNA

Sitio de **La Usina del PNA**, una publicación de trabajadores y trabajadoras del Primer Nivel de Atención de Bahía Blanca.

## Sitio publicado

https://lausinadelpna-glitch.github.io/lausinadelpna/

El sitio se publica desde `main` y la carpeta `/(root)` mediante GitHub Pages. La actualización del sitio puede demorar mientras se completa el despliegue.

## Páginas y enlaces

| Archivo | Contenido |
| --- | --- |
| `index.html` | Portada y enlaces a todas las secciones |
| `numero-0.html` | Índice del Número 0: CUIDAR |
| `editorial.html` | Texto provisional de presentación editorial |
| `relatos.html` | Sección Relatos |
| `pensar.html` | Pensar lo que nos pasa |
| `entrevistas.html` | Entrevistas, reportajes y debates |
| `quienes-somos.html` | Presentación del proyecto |
| `archivo.html` | Archivo de números |
| `styles.css` y `sections.css` | Identidad visual y páginas interiores |
| `script.js` | Menú móvil y botón compartir |

Todos los enlaces internos apuntan a archivos HTML reales del mismo repositorio, con rutas relativas. No hay que configurar otra carpeta para publicar estas páginas.

## Cómo editar

Para cambiar una página, abrí su archivo en GitHub, usá el ícono del lápiz (**Edit this file**), modificá el texto y confirmá el cambio con **Commit changes**. Si agregás un nuevo número o artículo, creá su página `.html` y enlazala desde la portada, el índice del número y el archivo, según corresponda.

**Estado editorial:** los textos de presentación son provisionales. No se deben presentar relatos, autorías o artículos completos como publicados hasta que el equipo haya aportado y revisado sus versiones definitivas.
