# La Usina del PNA

Sitio web de **La Usina del PNA**, una publicación de trabajadores y trabajadoras del Primer Nivel de Atención de Bahía Blanca.

## Estructura

- `index.html`: contenido y estructura editorial.
- `styles.css`: identidad visual y diseño responsive.
- `script.js`: menú móvil y botón para compartir.

## Publicar con GitHub Pages

1. Abrir **Settings** del repositorio.
2. Entrar en **Pages**.
3. En **Build and deployment**, elegir **Deploy from a branch**.
4. Seleccionar la rama **main** y la carpeta **/(root)**.
5. Guardar.

La URL esperada será:

`https://lausinadelpna-glitch.github.io/lausinadelpna/`

## Cómo actualizar contenido

Para cambios simples, editar `index.html` desde GitHub. Las secciones principales están identificadas con IDs claros:

- `numero-0`
- `editorial`
- `relatos`
- `pensar`
- `quienes-somos`
- `archivo`

La estructura está preparada para sumar próximos números sin cambiar la identidad general del sitio.
