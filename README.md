# La Usina del PNA

Sitio de **La Usina del PNA**, una publicación de trabajadores y trabajadoras del Primer Nivel de Atención de Bahía Blanca.

## Sitio

https://lausinadelpna-glitch.github.io/lausinadelpna/

GitHub Pages publica la rama `main` desde `/(root)`.

## Estructura

| Archivo | Contenido |
| --- | --- |
| `index.html` | Portada, acceso al Número 0 y a las secciones |
| `numero-0.html` | Índice del Número 0: CUIDAR |
| `editorial.html` | «Por qué empezamos a escribir», texto íntegro del borrador `N°0` |
| `pensar.html` | Artículo íntegro del documento `PENSAR EN LO QUE NOS PASA` |
| `relatos.html` | Relatos en revisión de confidencialidad |
| `entrevistas.html` | Entrevistas, reportajes y debates en preparación |
| `quienes-somos.html` | Presentación del proyecto |
| `archivo.html` | Archivo de números |
| `styles.css`, `sections.css` | Identidad visual y estilos de las páginas |
| `script.js` | Menú móvil y compartir |

Los documentos originales de trabajo de la editorial y del artículo están en la carpeta compartida `APS BAHIA BLANCA` de Google Drive. Sus borradores completos están incorporados al sitio; conservan anotaciones y requieren revisión editorial. La versión de Drive sigue siendo la fuente de trabajo.

**Confidencialidad:** los relatos clínicos originales contienen combinaciones de datos personales, de salud y familiares potencialmente identificables. No se deben volcar sin revisión a un repositorio y un sitio públicos. Antes de publicar, preparar una versión con anonimización rigurosa y confirmar los permisos editoriales que correspondan.

## Edición

Abrí el archivo correspondiente en GitHub, elegí el lápiz (**Edit this file**) y confirmá con **Commit changes**. Para un nuevo número o artículo, agregá una página `.html` y enlazala desde la portada y el índice. No publiques borradores de historias clínicas ni datos personales en el repositorio público.
